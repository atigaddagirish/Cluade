About nowcasts

IMD nowcasts are 3-hourly severe-weather alerts (thunderstorm, rain intensity, squall) issued per district / station. Colour code: green = no warning, yellow = watch, orange = alert, red = warning. If this panel shows "no data", set the correct district ID in ⚙ Settings (see README for how to find it).

Where this data comes from

All weather data is from the India Meteorological Department (IMD), Ministry of Earth Sciences — fetched live from IMD's public JSON services (mausam.imd.gov.in / city.imd.gov.in). If your network or IMD's CORS policy blocks a direct fetch, the app falls back to a relay copy: a GitHub Action in this repository fetches the same IMD endpoints every 30 min and publishes the raw JSON (badge shows RELAY with its age). Either way the origin of every number is IMD.

Official IMD channels for the same data: mausam.imd.gov.in · city.imd.gov.in · the "Mausam" app (IMD's official mobile app) · "Meghdoot" (agromet advisories) · "Damini" (lightning alerts).
