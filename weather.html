About nowcasts

IMD nowcasts are 3-hourly severe-weather alerts (thunderstorm, rain, squall, hail…) issued per station. Colour code: yellow = watch, orange = alert, red = warning (green/no-warning stations are omitted). This panel shows any active warning within 200 km of the location in the bar above, nearest first — change the coordinate and it recomputes instantly. Hazard-category labels are best-effort; the exact IMD legend confirms with the gateway key.

Where this data comes from

All weather data is from the India Meteorological Department (IMD), Ministry of Earth Sciences. Observations & warnings (any coordinate): a GitHub Action in this repo pulls IMD's nationwide GeoServer feed (reactjs.imd.gov.in/geoserver — 2,000+ Automatic Weather Stations, 400+ SYNOP stations, plus live nowcast warnings) every 30 min and republishes it CORS-open, so your phone can find the nearest station to any point you type — instantly, no third-party proxy, no key. 7-day forecast: from IMD's public Kurnool city page (per-coordinate forecast needs the api.imd.gov.in gateway key). Badges show data age. Since mid-2026 IMD's simple JSON APIs answer only whitelisted IPs (HTTP 401), which is why the relay exists.

Official IMD channels for the same data: mausam.imd.gov.in · city.imd.gov.in · the "Mausam" app (IMD's official mobile app) · "Meghdoot" (agromet advisories) · "Damini" (lightning alerts).
