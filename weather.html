About nowcasts

IMD nowcasts are 3-hourly severe-weather alerts (thunderstorm, rain, squall, hail…) issued per station. Colour code: yellow = watch, orange = alert, red = warning (green/no-warning stations are omitted). This panel shows any active warning within 200 km of the location in the bar above, nearest first — change the coordinate and it recomputes instantly. Hazard-category labels are best-effort; the exact IMD legend confirms with the gateway key.

Data source diagnostics

Where this data comes from

All weather data is from the India Meteorological Department (IMD), Ministry of Earth Sciences. Observations & warnings (any coordinate): a GitHub Action in this repo pulls IMD's nationwide GeoServer feed (reactjs.imd.gov.in/geoserver — 2,000+ Automatic Weather Stations, 400+ SYNOP stations, plus live nowcast warnings) every 30 min and republishes it CORS-open, so your phone can find the nearest station to any point you type — instantly, no third-party proxy, no key. 7-day forecast: per-coordinate point forecast from Open-Meteo (a free, CORS-open blend of the ECMWF-IFS, NOAA-GFS and DWD-ICON global models — the same gold-standard NWP that underpins most forecasts). It changes with the location you pick. IMD's own per-coordinate forecast unlocks with the api.imd.gov.in key. Badges show data age. Since mid-2026 IMD's simple JSON APIs answer only whitelisted IPs (HTTP 401), which is why the observation relay exists. Maps: IMD radar & rainfall map, plus a Windy embed (animated wind / rain / temperature / cloud layers, multi-model).

A general-purpose weather tool for any location in India — useful for agriculture (rain, wind for spraying, temperature), field work, travel and everyday planning.

Official IMD channels for the same data: mausam.imd.gov.in · city.imd.gov.in · the "Mausam" app (IMD's official app) · "Meghdoot" (agromet advisories for farmers) · "Damini" (lightning alerts).
