# commute-rain-alert (deploy branch)
Punctual bike-commute rain alerts as a Cloudflare Worker. One-click:
https://deploy.workers.cloudflare.com/?url=https://github.com/atigaddagirish/Cluade/tree/worker-deploy
After deploy, add Worker secrets TELEGRAM_BOT_TOKEN, TELEGRAM_CHAT_ID (and optional NTFY_TOPIC).
